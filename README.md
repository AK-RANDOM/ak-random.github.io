# AK Randomizer website

This repository publishes [Arknights Randomizer](https://ak-random.github.io/).
The application source and issue tracker live in [zoot-randomizer-arknights](https://github.com/AK-RANDOM/zoot-randomizer-arknights).

The Pages workflow checks the source repository's main branch hourly and publishes new revisions. Run **Publish Arknights Randomizer** manually from Actions to publish immediately.
